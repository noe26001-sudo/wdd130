Portfolio Site Plan

Daniel Noel

WDD 130

Overview

Purpose

This portfolio website will showcase my web design and development work from WDD 130. The site will present my projects, introduce who I am, and provide a way for visitors to learn about my skills, design choices, and contact information.

Audience

The main audience for this portfolio includes potential employers, instructors, classmates, and others who want to view my progress as a web developer. Visitors will be looking for clear navigation, professional design, examples of my work, and easy access to information about me.

Branding

Logo Concept

The portal uses a simple text wordmark, “Daniel Noel,” in the shared site header. This keeps the branding clear and avoids using a decorative image that does not add meaning.

Style Guide

Color Palette

The color palette uses deep navy for structure and headings, teal for accents and navigation, amber gold for hover and call-to-action elements, off-white for the page background, white for cards and surfaces, and dark charcoal for readable body text.

Role Color Name Hex Code Usage
Primary Deep Navy #1E293B Header, footer, and main headings
Secondary Teal Accent #0D9488 Navigation links, buttons, and highlights
Accent Amber Gold #F59E0B Hover states and call-to-action elements
Background Off-White #F8FAFC Page body background
Surface Pure White #FFFFFF Content containers and table backgrounds
Text Dark Charcoal #334155 Body text and paragraphs

Typography

Heading Font: Poppins

Paragraph Font: Open Sans

Normal paragraph example

This portfolio site will use clean typography, strong spacing, and simple visual structure to make the content easy to read. The design will focus on professionalism, clarity, and showcasing completed web projects.

Colored paragraph example
