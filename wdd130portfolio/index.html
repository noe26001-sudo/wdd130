Web Development Core Competencies

Key technical skills and best practices practiced throughout the WDD 130 coursework:

Semantic HTML5

Structuring content with semantic tags (header, nav, main, section, article, footer) for maximum accessibility and SEO.

CSS Grid & Flexbox

Building modern, fluid layouts with 2D grid systems and 1D flexbox alignment to ensure cross-device responsiveness.

Design Systems & Styling

Establishing cohesive branding with CSS custom properties, balanced color palettes, and Google Fonts typography pairings.

Accessible Forms & Tables

Designing user-friendly forms with explicit labels and validation, alongside semantic tabular data structures.
